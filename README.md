## Project Overview

This project is a front-end web application that displays the **CHI 2020 academic conference schedule**. Users can browse sessions by date and time slot, view session details including paper submissions and author information, and filter sessions by type — all without any page reload.

Built as part of the **Web Application Development** coursework at University College Dublin (UCD).

---

## Features

-  **Dynamic date & time selection** — dropdowns populated from a JSON data source via XMLHttpRequest
-  **Session detail viewer** — displays room, type, time, and linked paper submissions per slot
-  **Session type filter** — filter between All / Paper / Non-Paper sessions in real time
-  **DOI links** — each submission links directly to its paper via DOI URL
-  **No frameworks** — built entirely with Vanilla JS, no libraries or dependencies
